# Shift Notes — Archived (6-month + retention)

> **6-month archive destination** for per-shift notes per Story 0.9 P-13 + Story 0.10 precedent + ethics-protocol §6.

## Archive policy

Per ethics-protocol §6:
- Per-shift notes retained in `../` (parent `shift-notes/`) for **6 months**
- After 6 months, archived (NOT destroyed) here for cross-reference + further synthesis revision per Story 0.9 P-13 + P-04 precedent
- Operator OR host-helpline may request immediate destruction at any point — destruction is honored without archival

## Filename convention

Archived files retain their original filename with `-archived-YYYY-MM-DD` suffix:

```
operator-1-shift-1-archived-YYYY-MM-DD.md
operator-1-shift-2-archived-YYYY-MM-DD.md
```

## Pseudonymization invariants

Same as parent `shift-notes/` directory. All archived notes MUST satisfy:

- No operator real identity
- No host-helpline real institutional identity
- No caller identity (NEVER recorded)
- No caller-personal-content (NEVER recorded)
- All identifier fields use pseudonyms

## Author-commit state

At Task 5 author-commit, this directory is empty (no shift notes yet authored, no archives yet existing). Archived notes appear only after the 6-month retention window elapses, post-Task 8.
