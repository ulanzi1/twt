## 4. Key Insights / Lessons

### I-1 — Epic 8 is the integration epic: where frozen seams finally fire
Seven epics built primitives guarded by "no live caller yet." Epic 8 lit `cycle.frozen` (8.1), `contribution.*` (8.4), and `dispatch()` (8.8) — each de-risked in a controlled test *first*. The seam-vs-live discipline (`[[project_channels_no_live_dispatch_yet]]`) is now the house style, not a special case. The corollary from prior epics still holds: the seam exists as a primitive for an epic before anything fires it, and the first live caller is where the latent assumptions surface (8.8's `attempts[0]`-always-push bug lived undetected across all of Epic 5 because nothing had ever run the ladder).

### I-2 — A gate built this epic can indict last epic's committed code (8.10 → 7.10)
The temporal inverse of Epic 5's *"a gate scoped to last epic protects none of this epic's."* Mechanization pays forward (protects future surfaces) **and** backward (catches already-shipped violations). Corollary: shipping copy before the fence that governs it makes the fence's first job remediation — so the ordering discipline is to land the fence with, or before, the surface it governs. `[[feedback_gate_scope_semantic_coverage]]` now cuts both directions in time.

### I-3 — A pre-built forward-contract read view is inert-until-populated only if the producer emits the exact frozen NAME
8.3/8.6/8.8/8.9 all shipped honest "empty today, zero-code-change when Epic 9 lands" seams. That promise is a **name contract** — and H-2 is the proof that name drift silently keeps the view empty forever (a green-but-vacuous read that no internal test catches because both sides are internally consistent). The lesson: a forward-contract seam's teeth must assert the **name**, not just the shape — otherwise the "populates with zero code change" guarantee is only as good as an unverified string match across an epic boundary. AI-8-1 institutionalizes this for the mismatch/confirmed names.

### I-4 — The honesty frontier moved again, and widened into a class
E7 was "run the measurement." E8 built the instrument (8.12's three-disjoint-bucket loop breakdown — TWT-portion vs the excluded UPI-app round-trip vs member think-time, correctly avoiding the `total − round-trip` trap) but the field run is pending — *and* a whole family of human-in-the-loop gates (tone-review, device eyeball) now carries un-attested with no forcing function. The "re-commitment needs a gate" lesson (`[[feedback_record_unattested_no_backfill]]`) now applies to a **class** of human-attestation gates. The fix chosen is the same shape as every prior epic: give the class a ledger home with named closure owners (AI-8-2) rather than let per-story disclosures decay.
