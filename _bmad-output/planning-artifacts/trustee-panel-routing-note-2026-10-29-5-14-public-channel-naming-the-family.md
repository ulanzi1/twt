# The question

**In one sentence:** when a pool opens, the Trust will post a notice on its WhatsApp Channel and its Telegram channel. Should that
post name the deceased member whose family the pool supports, as you agreed in October, or name only the pool, as every public page
does until the member's own Terms allow their name?

**Why it cannot be decided without you:** in October you let the post name the family. You were told a WhatsApp Channel is public, and
you did not ask for the name to be left out. But since August your rule for every public place has been that a deceased member's name
appears there only if that member accepted Terms allowing it after death. The October note did not mention that rule. Both are your
rulings, and only you can say which governs here.

## The one fact that decides it

⭐ **A WhatsApp Channel can be found, followed and read by anyone. If the post names the family, the Trust itself publishes a deceased
member's name with neither the member's own agreement nor the family's.** Every other public place that can show that name rests on
one of the two. The drive page shows it only once the member's own Terms allow it, and today no member's Terms do, so it shows none.
The family's memorial shows it only in the family's own words, sent with their nominee's permission.

## What the post would say (English; the Hindi says the same)

| | The post |
|---|---|
| Naming the family | *"Pool [pool] is now open, in support of [name]'s family. If you are assigned to this pool, please open the app to contribute."* |
| Naming only the pool | *"Pool [pool] is now open. If you are assigned to this pool, please open the app to contribute."* |

The last-day post (*"Today, [date], is the last day of this cycle…"*) names no one under any option.

# What you are choosing between

| | Option | What changes for a person | Cost |
|---|---|---|---|
| **A** | **Name the family, as October agreed.** | Anyone who follows either channel, member or not, reads which family each pool supports. | A deceased member is named in public with no basis of their own. That departs from the rule every public page follows, and counsel has not been asked whether it is lawful. A second question follows: the full name, or the shorter form the public pages use, which leaves out a one-word name. |
| **B** | **Follow the public pages' rule.** Name a family only when the deceased member accepted Terms that allow it. | Today every post names only the pool. A member who sees the post opens the app to learn which family it is for. | It narrows your October ruling for these posts. A member the app's notification did not reach is exactly who the channel exists for, and that member sees no name in the post. Names appear only after counsel's clause is written and pinned (overdue since 2026-09-07) **and** a further build reads each member's own Terms. |
| **C** | **Name the family on Telegram, made a private, invite-only channel. Post the pool only on WhatsApp.** | Members who join the Telegram channel through the app read the name; WhatsApp followers do not. | Two sets of words, and the Telegram channel cannot be found by search. An invite link can be forwarded, so private is not secret; anyone holding the link can read the name. |

**Our reading:** B — **because** it keeps one rule for every public place you have ruled on. The name is still in the app for every
member who opens it. Only the channel post, which anyone can read, leaves it out until the member's own Terms allow it. If you prefer A,
please also say which name form.

# In plain English

The Trust will soon have a WhatsApp Channel and a Telegram channel. When a pool opens, the system posts a short notice there. In
October you agreed that the notice names the family the pool is for. You were told the WhatsApp Channel is public, and you did not object.

What you were not told is that, since August, every public web page follows a rule you set. A deceased member's name appears there
only if that member had accepted Terms allowing it after death. Those Terms are not written yet, so today no public page names anyone.
The family's own memorial is different, because the family chose to publish it.

So the October answer would make the channel the one public place where the Trust names a deceased member on nobody's permission. We
suggest following the same rule as the web pages: name only the pool until the member's own Terms allow the name. Members still see
the name in the app. If you prefer to keep October's answer, please say whether the full name or the shorter public form is used. Until
you answer, nothing is posted. If this summary and the evidence below ever disagree, the evidence is the record.
