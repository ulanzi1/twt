Re-tune the DATA, never add engine logic. `[[project_niyamavali_precedence_is_provenance]]`
- **NEVER auto-deny (SM-1 C7, the whole point of this story).** R5/R9/R14 produce **flags** and **routing slugs** — the consumer (Epic 6) makes the actual deny decision via State Trustee review/voting. No family payload may have a `deny`/`ineligible` `on_pass`/`on_fail`. `never_auto_deny:true`; `prd.md:370` "Final denial requires explicit trustee action — never auto-denial — but the engine surfaces the trigger."
- **Determinism.** Pure core: no clock, no randomness, no mutable module state (time passed IN via `ctx.evaluatedAt`, DB-authoritative). Every collection emitted in explicit stable order (sorted by `clause_id`). Story 4.6 runs the pure core 100× across threads and fails CI as a P0 on any byte-variance.
