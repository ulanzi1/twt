# Interview Notes — Archived

**Authority:** ethics-protocol.md §2(e) data-retention discipline · per-interview-note-schema.md authoring discipline

**Scope:** Archived per-interview notes whose 6-month active-retention period has elapsed. Notes are moved here (not destroyed) per ethics-protocol §2(e) update at review-patch.

## Archiving discipline

- Active per-interview notes live in `interview-notes/` (e.g., `bereaved-spouse-1.md`).
- After 6 months from interview date, the note is **archived (not destroyed)**: moved to this directory with an `[archived-YYYY-MM-DD]` marker appended at the top of the file.
- Archived notes remain pseudonymized per ethics-protocol §4 — no substantive identity in any archived file.
- Archived notes are immutable: no edits post-archival. Post-archival supersession entries (if required by withdrawal events) are appended as `[addendum-YYYY-MM-DD]` blocks per per-interview-note-schema.md §21.
