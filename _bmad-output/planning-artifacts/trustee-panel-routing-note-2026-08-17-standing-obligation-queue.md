## Why this note exists

Every governance ruling in this lineage since 2026-08-07 has ended by restating a count of standing
Panel obligations — *five*, then *seven*, then *nine* — and then saying, in terms, that the entry
discharged none of them.

**The count is the only thing that has ever been recorded. The queue has never been written down as a
register.** It lives as prose inside decision entries and inside `deferred-work.md` section footers,
re-derived by hand each time, and the last enumeration says so about itself:

> *"⚠ **Reported as LAST ENUMERATED, not re-enumerated.** … **NINE is the last recorded figure, not a
> verified current one.**"* — `deferred-work.md:5256-5262` (Story 10.22, 2026-08-16)

That is precisely the decay shape this lineage exists to abolish ([[project_r7_fact_producer_unbuilt]];
[[feedback_mechanization_split_commitment]] — *decay concentrates in the un-mechanized half*). An
obligation whose only record is a number in someone else's footnote is an obligation that will be lost.

So this note does two things. It **re-derives the count** — and finds it is **TEN**, not nine. And it
asks the Panel to **adopt a register**, so the eleventh obligation is added to a list rather than to a
sentence.
