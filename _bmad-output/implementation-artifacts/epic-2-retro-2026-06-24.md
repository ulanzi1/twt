### The headline

> Epic 1's thesis was *enforced rules beat remembered rules*. Epic 2's sharpening is the **corollary**: a gate is only as strong as the property it actually asserts. The wins came where gates checked the right thing (the forward-compat teeth-activation); the one miss came where a gate checked a *proxy* for the thing (cadence file existence, not row population).

## 3. What Was Hard / What Slowed Us Down

### H-1 — The cadence instrument got a gate, but the gate watches the wrong property *(the headline miss)*
AI-1 said "stand up `ai-cadence-actuals.md` and gate it." The file exists, `scripts/cadence-check/check.ts` enforces it, ci:local is green — the **structural** fix worked. But the per-story rows were never filled in: the Epic 2 table still reads *"no stories started yet"* with all seven `done`. The gate asserts **existence + currency**, not **population** — so the 80 hr/wk NET assumption is **un-attested for a third consecutive epic** (0, 1, 2). This is Epic 1's lesson, sneakier: last time the commitment had no gate; this time it had a gate that checked a proxy.

### H-2 — Recurring review finding: domain-level guard missing where only the HTTP/contracts layer enforced the invariant
Same shape in at least three stories: 2.3 (`splitClause`/`mergeClauses` accept empty arrays — P4/P5), 2.6 (`createTcVersion` allows empty pins; `listTcVersions` no cap — P4/P6), 2.7 (`listConsents` negative limit bypasses the 200-row cap — P2). "The primitive trusts its consumer," but a direct domain caller (test, seed, future internal) bypasses the Zod boundary. Caught every time *in review*, never *before*.

### H-3 — Concurrency / TOCTOU on registry write paths, re-discovered per story
2.4 concurrent publish (P1), 2.6 concurrent create → unmapped `23505` (P1) + provenance-hash version divergence (P10), 2.7 double-revoke (P1). The fix family is now well-understood (`FOR UPDATE`; map unique-violation → typed 409; re-read on 0-row UPDATE) — but the discovery cost was paid independently on each write surface.

### H-4 — Test quality lagged code quality: vacuous and tautological assertions
2.6 alone: positive RLS SELECT assertions that pass on *empty* rows (P12), a `PERMISSION_CATALOG_VERSION` check comparing a constant to itself (P15), a missing symmetric assertion (P17). 2.1 had untested React hooks (P3). Tests that would stay green even if the thing under test were broken.

### H-5 — Governance carry-over (now resolved)
Three un-attested trustee ratifications rode toward the epic boundary — ADR-0023 (T&C), ADR-0024 (consent), and the `/terms` inventory leg — all DPDPA-sensitive and signup-load-bearing. **Resolved at retro:** BigDev confirms the Trustee Panel has ratified all three and committed (the 2.5 inventory leg was already attested via Decision 2026-06-23-060). `.decision-log.md` is the system of record.

### H-6 — The 2.6 ledger flip itself decayed (briefly)
2.6's story file read `Status: done` while the `sprint-status.yaml` row lagged at `review` — the one artifact in the epic with **no gate** is the one that drifted. Reconciled (now `done`).

## 4. Key Insights / Lessons

### I-1 — A gate is only as strong as the property it asserts
AI-1 had a gate and still half-decayed, because it checked file existence rather than row population. The Epic 1 fix ("give it a gate") sharpens to: **give it a gate that checks the thing you actually care about.** This is why the Epic 2 action (AI-2-2) gates *behavior*, not just authors a convention doc.

### I-2 — Recurring review findings are a mechanization signal, not a discipline problem
Domain-guards (H-2), TOCTOU (H-3), and vacuous tests (H-4) recurred because nothing mechanical watched them — the exact dynamic the program's own thesis warns about. The fix is a checkpoint, not "review harder."

### I-3 — Integrity over the appearance of validation, again
The ratchet stayed un-gamed and the cadence gap is recorded **un-attested, not backfilled**. "We committed to measure, we built the instrument, the rows are empty, we are recording that openly and retiring the basis" is more defensible than fabricated hours. Same closure-language discipline applied to our own process.

### I-4 — The forward-compat primitive pattern is now proven, not hopeful
Epic 1's riskiest bet — gates that are green-by-construction until a consumer lands — flipped to enforcing in full at 2.3/2.5. The "land-once primitive → consumer wires with teeth" rhythm is now the default architectural motion entering Epic 3.
