# Interview Protocol — P0-2b Bereaved-Spouse Conversation

**Authority:** ethics-protocol.md (this directory) — operational conduct rules per ethics-protocol §3 expanded into an actionable runbook · question-bank.md · pattern-4-evaluation-worksheet.md · per-interview-note-schema.md · informed-consent-template-hindi.md · informed-consent-template-english.md

**Scope:** Conduct runbook for the 1 bereaved-spouse conversation per Story 0.9, with **§0 pre-recruitment trustee-approval checklist** (P0-2b-distinct precondition) + **§4 mid-interview Pattern 4 sample-copy opt-in offer** (P0-2b-distinct discipline).

## §0 Pre-recruitment trustee-approval checklist

**P0-2b-distinct precondition.** Solo Builder MUST verify the trustee-approval row exists in `trustee-review-log.md` BEFORE approaching any candidate. Checklist:

- [ ] Trustee Panel meeting held to review the framework + ethics-protocol + this interview-protocol + pattern-4-evaluation-worksheet + recruitment-path candidates.
- [ ] Trustee verdict appended to `trustee-review-log.md`: `review_id` = `pre-conversation-001`; `review_scope` = `approval-for-recruitment-pre-conversation`; `review_verdict` = `approved-for-recruitment`; `sign-off_note` = explicit "Recruitment may begin" attestation.
- [ ] `.decision-log.md` Decision 2026-05-30-009-trustee-approval entry appended per the Story 0.8 trustee-review-N supersession schema.
- [ ] Solo Builder confirms the approval row exists by reading `trustee-review-log.md` immediately before approaching any candidate.

**If approval is `revision-list-pending-approval`:** Solo Builder revises the framework per the revision_list; re-presents to Trustee Panel; approval lifecycle iterates until `approved-for-recruitment` verdict. No recruitment activity occurs in the interim.

**If approval is delayed:** Solo Builder waits. No recruitment activity occurs without the approval row. Trustee Panel chair fallback per README §5 may grant the approval in trustee-incapacitation scenarios (time-bounded 30 days, requires second-trustee re-review before lifting).

## §1 Pre-interview checklist

Within 24-48 hours before the scheduled conversation:

- [ ] **Hindi-comprehension pre-confirmation (D-07):** Researcher confirms with the trustee intermediary that the spouse can understand spoken Hindi at a conversational level before the scheduled date. If any concern arises, researcher confirms Hindi comprehension directly at the start of the conversation (before consent form review). If the spouse cannot understand Hindi, the conversation does not proceed per ethics-protocol §3.2.

- [ ] **Consent form printed in Hindi** (informed-consent-template-hindi.md) + English mirror printed (informed-consent-template-english.md) as a backup. Two copies: one for spouse to retain, one for the protocol directory under pseudonymized identity.
- [ ] **Recording device prepared if spouse agreed to audio recording** per ethics-protocol §2 c. If spouse opted for notes-only (researcher's default preference), no recording device is brought.
- [ ] **Question-bank readied as prompt list** (NOT a script). Researcher reviews the prompts mentally; no printed copy is carried into the conversation (to avoid clipboard ostentation per ethics-protocol §3.4).
- [ ] **Pattern 4 sample-copy cards prepared for opt-in mid-interview presentation** per ethics-protocol §3.7. Format ADR-deferred per README §8 — at first conversation, the researcher uses whichever format minimizes invasiveness for the spouse (e.g., printed cards if the spouse is literate + comfortable with printed material; spoken aloud if the spouse prefers; phone-screen-shown if the spouse is comfortable with phone reading). The researcher carries multiple formats to allow spouse choice mid-interview.
- [ ] **Per-interview-note template opened** in researcher's secure storage; pseudonym `Bereaved-Spouse-1` pre-assigned per recruitment-log row.
- [ ] **Researcher's identifying-marker minimal:** plain comfortable clothes; no formal attire; no clipboard ostentation; no recording equipment displayed before consent; no TWT-branded materials (researcher is a neutral researcher, not a TWT representative).
- [ ] **Researcher arrives 10-15 minutes early** at the spouse's chosen setting; waits patiently if spouse is delayed; does NOT pressure for prompt start.
- [ ] **Researcher confirms with the trustee intermediary** (the recruitment-path contact) that the spouse is still willing + the setting is confirmed + any last-minute concerns are addressed.

## §2 Opening

The opening establishes the witnessing register + rapport before any dimension prompts. Pacing: **5-10 minutes** of warm-up before engaging dimension prompts (distinct from Story 0.8's 2-3 minutes — bereavement-context requires extra time).

### §2.1 Greeting (in Hindi, witnessing register per ethics-protocol §3.4)

Researcher greets the spouse in Hindi with the witnessing register:

> "Namaste. Main BigDev hoon. Main TWT ka kaam kar raha hoon — Bihar ke shikshakon ke liye ek welfare trust banaya ja raha hai. Aap ne is baatcheet ke liye samay diya — iska main shukriya karta hoon. Main yahaan aapse seekhne ke liye hoon. Aap jab tak chahein, jitni baat karna chahein — main sun raha hoon. Aap kabhi bhi ruk sakte hain, savaal pooch sakte hain, ya jaa sakte hain."

(English: "Namaste. I'm BigDev. I'm working on TWT — a welfare trust being built for Bihar teachers. You gave time for this conversation — I thank you for that. I'm here to learn from you. As long as you wish, as much as you wish to speak — I am listening. You can pause at any time, ask questions, or leave.")

### §2.2 Self-introduction + TWT purpose (60-90 seconds, no solicitation)

Researcher introduces self + TWT purpose briefly, without solicitation:

> "Main software banata hoon. TWT abhi tak shuru nahin hua — hum log usko design kar rahe hain. Jab kisi shikshak ke ghar mein kuch hota hai, parivar ko sahara dene ka tareeka theek se banaya jaye — yeh humara kaam hai. Iske liye, jin logon ne is anubhav se gujare hain — jaise aapne — unse seekhna humein zaroori lagta hai. Aap TWT mein judne wale nahin hain — bilkul bhi. Hum aap se kuch bhi nahin maang rahe, sirf seekhna chahte hain."

(English: "I build software. TWT hasn't started yet — we're designing it. When something happens at a teacher's home, the way the family is supported needs to be built right — that's our work. For this, we need to learn from people who have gone through this experience — like you. You are not joining TWT — absolutely not. We are not asking you for anything, only seeking to learn.")

### §2.3 Warm acknowledgment of grief (witnessing register, NOT pity or consolation per ethics-protocol §3.4)

Researcher offers warm acknowledgment with the witnessing register:

> "Aapke saath jo hua, mujhe iska gehra dukh hai. Main yahaan aapse seekhne ke liye hoon — kisi bhi tarah ki advise ya counseling ke liye nahin. Aap jo bhi batana chahein, woh sahi hai. Aap kuch bhi nahin batana chahein, woh bhi theek hai."

(English: "What happened with you, I feel deep sorrow for it. I'm here to learn from you — not for any kind of advice or counseling. Whatever you wish to say is right. Whatever you don't wish to say is also right.")

Researcher does NOT:
- Express pity ("Hai re, kitna dukh hua aapko").
- Attempt consolation ("Sab theek ho jayega").
- Ask "How are you feeling?" (clinical register).

### §2.4 Consent form review + signature

Researcher walks through the Hindi informed-consent-template-hindi.md with the spouse:
- Reads each section (क)-(ज) + §2-bis aloud at the spouse's pace per the canonical ordering.
- Explicitly highlights the **§2-bis re-consent-for-quotation checkbox** — explains that no verbatim quotes will appear in any document unless the spouse explicitly re-confirms at the specific quote post-conversation.
- Explicitly highlights the **§2-tris trustee-approval transparency line** — names the approving trustees + provides their contact for any complaint.
- Allows spouse to ask questions; researcher answers without pressure.
- Spouse signs the Hindi consent form. Researcher signs as witness. Spouse retains one copy; one copy is filed in the protocol directory under pseudonymized identity.
- **Verbal-only consent (D-03 — edge case):** If spouse declines to sign but confirms willingness verbally, researcher **explicitly confirms verbal consent aloud before any note-taking begins** ("Kya aap is baatcheet mein voluntarily participate karna chahte hain?") and notes "Verbal consent given — participant declined to sign" in the per-interview note. The conversation is treated as informational only — no verbatim notes; notes destroyed immediately after; NOT cited as research in synthesis. This is an edge case; typically spouses willing to participate are willing to sign after the consent form is explained.
- **Illiterate-participant alternative (P-14):** If spouse is unable to sign, thumbprint in lieu of signature is acceptable per ethics-protocol §2. Researcher reconfirms verbal consent before taking the thumbprint.

### §2.5 Recording-or-notes choice confirmed

Researcher asks: "Kya aap chahte hain ki main audio record karoon ya sirf notes likhoon?" — spouse chooses. Researcher's preference is notes-only, but the spouse decides.

If audio recording: explicit reconfirmation: "Audio start kar raha hoon. Aap kabhi bhi 'ruk jaiye' bol kar pause kar sakte hain — main bilkul rok dunga."

### §2.6 Conversational warm-up (5-10 minutes of non-sensitive topics)

Researcher engages in non-sensitive conversation before any dimension prompt — this is the bereavement-context warm-up distinct from Story 0.8's brief warm-up. Topics:
- Researcher's journey to the location (traffic / weather / local landmarks).
- The setting itself (e.g., the family courtyard, the village — non-identifying observations).
- General Bihar topics that the spouse may engage with (e.g., recent local news that the spouse may have heard).
- Spouse's general daily routine (e.g., "Aaj ka din kaisa raha?" — at a non-intrusive level).

Researcher follows the spouse's lead. If spouse engages briefly + signals readiness to begin, researcher transitions to §3. If spouse engages at length, researcher honors the pacing.

## §3 Dimension exploration

Researcher engages the 5 AC-named dimensions in **spouse-led order** — NOT a fixed sequence. Discipline:

### §3.1 Spouse-led order

If the spouse anchors on a specific dimension first (e.g., spontaneously speaks about document-gathering), researcher follows their lead. If the spouse is open to researcher-led order, researcher typically begins with a less sensitive dimension (e.g., dimension-2 document-gathering experience) before engaging more sensitive dimensions (e.g., dimension-1 emotional pace tolerance, dimension-5 role of family/community).

### §3.2 Open-ended prompts per question-bank

Researcher uses prompts from question-bank.md §1-§5 as conversation starters, NOT as a fixed sequence. Each prompt is open-ended; researcher does NOT pre-frame the answer.

### §3.3 Silence is honored

Researcher waits **≥5 seconds** after a spouse response before filling silence (bereavement-context pacing extension distinct from Story 0.8's ≥3-second wait). Silence is the spouse's space to think + feel; researcher does not fill it.

### §3.4 Spouse-led grief discipline (P0-2b-distinct per ethics-protocol §3.6)

Researcher does NOT initiate grief topics. The spouse leads ALL bereavement-specific content depth. If a dimension prompt could naturally surface grief content but the spouse does not voluntarily engage with grief, researcher does NOT prompt for it. The dimension may be marked partial-coverage in the per-interview note; this is honest research outcome.

### §3.5 No TWT-specific framing

Researcher does NOT introduce TWT-specific terminology ("fursat", "human shepherd", "dignified-vs-transactional", "Ravi-mode", "Sunita-mode", "Yogdaan Bahi", "Pool Karna", etc.) until the spouse has independently generated the concept. The spouse defines their own categories in their own words.

**Anti-leading carve-out for §4 opt-in surfaces (P-05):** The no-TWT-framing rule applies to §3 dimension exploration only. §4 (mid-interview Pattern 4 sample-copy opt-in) and §4.5 (cross-cutting grief-grammar opt-in) are evaluation instruments that necessarily introduce TWT-specific content once the spouse opts in. The researcher presents TWT's sample copy and design decisions as evaluation stimuli — this is the evaluation methodology, not a violation of the anti-leading rule.

### §3.6 Re-consent-for-quotation discipline (per ethics-protocol §2-bis)

Researcher records observations in paraphrased form during the conversation. If the researcher hears a phrasing that may merit verbatim capture for synthesis fidelity, researcher silently flags it mentally; researcher does NOT directly transcribe verbatim into notes. Verbatim re-consent is sought post-conversation per ethics-protocol §2-bis workflow.

### §3.7 No correction of contradicting statements

If the spouse states something that contradicts a PRD/UX assumption (e.g., the spouse describes a claim process that contradicts the "named human shepherd per claim" assumption), researcher does NOT correct. The contradiction goes into the per-interview note `divergence-flags` column + the synthesis divergence-log row at Task 9.

### §3.8 Participant-initiated topics outside the 5 dimensions

If the spouse anchors on a topic outside the 5 AC-named dimensions (e.g., the spouse speaks at length about a cultural-grammar element not covered by the 5 dimensions), researcher follows their lead AND notes the observation as potential dimension-6 cultural-grammar cross-cutting content in the per-interview note.

## §4 Mid-interview Pattern 4 sample-copy opt-in offer (P0-2b-distinct per ethics-protocol §3.7)

**Timing:** After rapport is established AND dimensions 1-3 (or 1-2 if the spouse has anchored on document-gathering first) have been substantively engaged. Typically at the 30-40 minute mark of the conversation.

### §4.1 Researcher offers the opt-in

Researcher offers the Pattern 4 sample-copy review with explicit acknowledgment of optionality (per ethics-protocol §3.7):

> "TWT ki team ne kuch sample messages likhe hain — jo error ya problem ke time members ko dikhte hain. Agar aap chahen, hum kuch dikha sakte hain aur poochh sakte hain ki kya woh thik lagte hain ya behtar ho sakte hain — par agar aap aaram se nahin hain to bilkul zaroori nahin."

(English: "TWT's team has written some sample messages that members see when there's an error or problem. If you'd like, we can show some and ask whether they feel right or could be better — but if you're not comfortable, it's absolutely not required.")

### §4.2 Spouse may decline

If spouse declines:
- All 8 sample-copy rows + 7 cross-cutting grief-grammar rows are marked `not-evaluated-due-to-spouse-non-engagement` in the Pattern 4 evaluation worksheet.
- Researcher does NOT ask for explanation.
- Conversation continues with §5 closing.

### §4.3 Spouse may opt in fully or partially

If spouse opts in:
- Researcher asks: "Kis format mein dikhana behtar lagega — printed cards par, ya main padh kar sunau, ya phone mein dikha doon?" — spouse chooses format.
- Researcher presents one sample at a time per question-bank.md §6 prompts.
- Per-sample workflow:
  1. Researcher reads/shows the sample copy (Hindi + English from UX spec lines 2349-2360).
  2. Researcher asks: "Yeh message agar aapke samne aata, to kaisa lagta? Theek lagta, ya behtar ho sakta?"
  3. Spouse responds; researcher captures verdict ∈ {`lands-as-intended`, `requires-revision-with-proposed-copy`, `requires-deeper-redesign`} + paraphrased observation.
  4. If verdict is `requires-revision-with-proposed-copy`, researcher gently asks: "Aapke hisab se behtar shabd kya ho sakte hain?" — spouse proposes revision; researcher captures proposed Hindi+English copy.
  5. If spouse declines any specific sample mid-review, that sample is marked `not-evaluated-due-to-spouse-non-engagement` + researcher moves to next.

### §4.4 Spouse-initiated correction is NOT permitted

The researcher captures the spouse's verdict + paraphrased observation; the researcher does NOT defend the sample copy or argue for it. The spouse is the authority.

### §4.4a Distress mid-Pattern 4 (P-19)

If the spouse shows signs of distress during the Pattern 4 sample-copy review (e.g., a sample triggers grief associations unexpectedly), researcher follows ethics-protocol §7 escalation path:
1. **Immediately pause** the sample-copy review.
2. Offer: "Hum yahaan ruk sakte hain. Kya aap theek hain? Hum aage jaayein ya yahaan ruk jaayein?"
3. Honor spouse's response — if spouse opts to continue, researcher returns to the next sample only if the spouse initiates it; if spouse opts to end Pattern 4 review, remaining samples are marked `not-evaluated-due-to-spouse-non-engagement`.
4. If spouse opts to end the entire conversation, §5 withdrawal-during-conversation logic applies.
5. Researcher does NOT attempt to reassure the spouse that a specific sample copy is "fine" or "not serious" — researcher's role is to honor the pause, not to minimize the distress.

### §4.5 Cross-cutting grief-grammar prompts (§7 of question-bank, typically late-interview)

After Pattern 4 sample-copy review (if opted in), researcher may offer §7 cross-cutting grief-grammar prompts opt-in:

> "Ek aur baat — TWT mein humne kuch general design decisions liye hain jo grief ke time members ke saath kaise pesh aate hain. Agar aap chahen, hum un par bhi baat kar sakte hain — par yeh bhi zaroori nahin."

(English: "One more thing — in TWT we've taken some general design decisions about how the system should interact with members in times of grief. If you'd like, we can discuss those too — but this is also not required.")

Same workflow as §4.1-§4.4. Per-row verdicts captured for the 7 cross-cutting grief-grammar rows.

## §5 Closing

### §5.1 Open-floor close

Researcher asks: "Kya aap kuch aur batana chahte hain jo maine nahin poocha? Kuch jo aapko zaroori lagta hai TWT ke design ke liye?"

(English: "Is there anything else you wish to say that I haven't asked? Something you feel is important for TWT's design?")

Spouse-initiated content is captured in dimension-6 cultural-grammar cross-cutting column of the per-interview note.

### §5.2 Reach-back permission + re-consent-for-quotation confirmation

Researcher asks (only if §2-bis re-consent-for-quotation checkbox was opted in):

> "Agar synthesis likhte hue mujhe aapke kuch specific shabd zaroori lagein, to kya main aapse — trustee ke through — re-confirm kar sakta hoon ki kya woh shabd publish kiye ja sakte hain? Yeh bhi aap kisi bhi quote ke liye mana kar sakte hain."

(English: "If, when writing the synthesis, I find some specific words of yours essential, can I — through the trustee — re-confirm whether those words can be published? You can decline this for any specific quote.")

If spouse declines: researcher confirms that no verbatim quotes will appear in any artifact; paraphrase-only synthesis.

### §5.3 Withdrawal-right + quotation-withdrawal-right reconfirmation

Researcher reconfirms:

> "Aap kabhi bhi withdraw kar sakte hain — is baatcheet ko publish na karne ke liye, ya kisi specific quote ko hatane ke liye. Bas trustee ko bata dijiye — main turant follow karunga."

(English: "You can withdraw at any time — to not publish this conversation, or to remove a specific quote. Just tell the trustee — I'll follow immediately.")

### §5.4 Provide withdrawal-contact

Researcher provides a small printed card with:
- Trustee Panel intermediary's name + phone number (the recruitment-path trustee).
- Pseudonym reference (`Bereaved-Spouse-1`) so the spouse can reference the conversation if needed.
- Withdrawal-right reminder in Hindi.

The card does NOT carry Solo Builder's direct contact (to avoid bypassing the trustee-mediated channel per ethics-protocol §2-bis workflow).

### §5.5 Gratitude

Researcher closes with simple gratitude:

> "Aapke samay ka aur aapke baatcheet ka shukriya. Aapne TWT ke design mein bahut bara yogdan diya hai."

(English: "Thank you for your time and your conversation. You have made a significant contribution to TWT's design.")

Researcher does NOT extend the closing with additional solicitation or follow-up requests.

## §6 Post-interview

Within 24 hours of conversation:

### §6.1 Per-interview note authored per per-interview-note-schema.md

- Researcher authors `interview-notes/bereaved-spouse-1.md` per the schema.
- All observations are **paraphrased** (verbatim quotes only via §2-bis re-consent rule; any candidate verbatim is captured in the `quotation_log` table with status `re-consent-pending`).
- Per-dimension observations: ≥3 substantive observations per engaged dimension expected; dimensions not engaged are marked partial-coverage.
- Pattern 4 evaluation worksheet populated for evaluated samples (verdicts + proposed_revision if applicable) OR marked `not-evaluated-due-to-spouse-non-engagement` for declined samples.
- Divergence-flags inserted for any observation contradicting an assumption-inventory row.
- `notes_authored_within_24h` timestamp recorded.

### §6.2 Raw recording (if applicable) transferred to secure storage

- Raw recording transferred to researcher's secure storage (encrypted at rest).
- Retention timer started (30 days post-synthesis-author-commit per ethics-protocol §6).
- Recording file path + retention end date logged in recruitment-log `recording_storage_log` column (added at recording-transfer time).
- **Device failure note (P-18):** If recording device failed mid-interview, log the failure timestamp in the `recording_storage_log` column: "Recording file covers [start] to [failure-timestamp]; notes-only for remainder." Only the pre-failure content is stored; the notes-only remainder is part of the per-interview note.

### §6.3 Per-interview note pseudonymization verified

- Researcher reviews the per-interview note for any inadvertent identity leak (village-name, school-name, specific named family member, specific named colleague, specific identifying incident).
- Any identity leak is paraphrased to non-identifying granularity per ethics-protocol §4.

### §6.4 Recruitment-log updated

- Recruitment-log row updated with `interview_conducted_date` + `quotation_re-consent_engagement` initial status (e.g., `pending-synthesis` if re-consent checkbox was opted in; `paraphrase-only` if not opted in).

### §6.5 Trustee intermediary notified of completion

- Researcher notifies the trustee intermediary (the recruitment-path trustee) that the conversation has been completed + the spouse's well-being post-conversation (if any concern arose).
- Trustee intermediary may follow up with the spouse at the trustee's discretion (researcher does NOT mediate this follow-up).
