## 1. Epic Summary

Epic 11a is **the Public Trust Identity Shell — and, in practice, the epic where the project learned the
difference between built and live**. Six stories, planned as six, shipped as six: the first epic since
Epic 5 to ship exactly its planned scope. That is not because it was quiet. It is because the correction
happened **before** authoring, in a blocking pre-authoring session, instead of during the epic as fourteen
minted stories.

## 2. What Went Well

### W-1 — A blocking pre-authoring action item ran, and it changed the epic
**AI-10-4 is the first blocking planning gate this project has issued, and it held.** No 11a.1 commit
exists before the session landed. The session did not merely rule the four SD-1 rows to *build / narrow /
defer*: BigDev reframed the problem mid-session, and **R7** turned a fixed six-column directory into a
Pariwar-selected attribute model. That reframe then propagated into `2026-08-19-133` (CREATE / ENABLE /
GRANT as three separate layers, no layer implying the next), `-134` (the scope-dimension model, with
`district_admin` explicitly **not** re-opened), and `-137` (hierarchy drift answered by **migration**, with
ambiguous cases requiring **member choice** and node deletion **forbidden** — the system must never
silently guess a mapping).

⭐ The counterfactual is the value: ruling the four rows *as originally framed* would have produced a fixed
six-column directory that is correct for Shikshak Pariwar and wrong for every tenant after it.

### W-2 — The vacuous gate was found, armed, and the arming was proven by planting a leak
`loadSnapshots(): return []` was **DELETED, not fixed**. The gate output went from `0 surface(s)` to
**8 surfaces / 23 tier-classified fields / 1 escalation with its decision ref cross-checked**. 11a.3's AC4
then required the discharge be proven by **planting an actual tier leak and watching CI fail** — not by
asserting the leg now works.

⭐ And 11a.1 added a check no AC asked for: **a `renders: false` surface whose route later ships fails as
STALE**. That is a gate arming itself against the *next* story — 11a.3 structurally could not ship
`/members` and forget to flip the flag.

### W-3 — Four defective epic ACs, four written reconciliations, zero silent deviations
Each contradiction got a Decision entry stating it in plain words, per `[[feedback_closure_language_precision]]`:

- **11a.1** — the AC's *"per-surface, per-field entries"* described a fixed schema; R7 ruled the attribute
  set Pariwar-selected. Reconciled in the `epics.md` prose as a **RECONCILED** block, not a silent rewrite.
- **11a.2** — `2026-08-20-141`: *"the epic AC and `architecture.md` CONTRADICT each other on
  `<AuthenticatedFragment>`, and the AC's version is UNBUILDABLE."* The architecture won.
- **11a.3** — the AC's own tier table is SD-1's origin; the `authenticated_member` column *"has NO VIEWER"*
  and was structurally unbuildable at that story.
- **11a.6** — `2026-08-22-153`: the epic AC *"describes a component that already shipped"* (`<BannerHost>`).
  Building it literally would have produced a **third** banner surface, one story after 11a.5 spent a whole
  ruling (D7(a) + `route-suppression.ts`) stopping one banner from rendering twice.

⭐ **And 11a.4's D1 was WITHDRAWN on the merits** — the three masking techniques were refused because the
trust's own contact channel exists **to be reachable**. That is the Panel's standing direction working:
stop and surface the conflict rather than inventing a rule.

### W-4 — A process failure was disclosed rather than backfilled
`2026-08-21-145` records that the per-Pariwar publication kill switch *"shipped implementation-first with
no governance entry"* — recorded as a **process failure disclosed**, ⛔ explicitly **not** backfilled into a
pre-dated entry ([[feedback_record_unattested_no_backfill]]). Given that
`[[feedback_governance_commits_precede_implementation]]` was Epic 10's proudest mechanism — verifiable from
commit history itself — catching and confessing its one breach is the stronger outcome than an unbroken
record would have been.

### W-5 — The review layer kept finding **vacuous and gameable tests**, including its own prior passes
11a.6's single pass closed five:
- a tautological a11y assertion whose `OR` collapsed to a vacuous check;
- a *"zero banner-file edits"* test tightened from one hardcoded string per file to a **byte-for-byte
  SHA-256 pin** against each file's content at the story's own `baseline_commit`;
- a *"no clock"* arity-only assertion strengthened with a real fake-timer determinism proof;
- a **gameable** dismissal-key-format guard (it matched exactly one template-literal spelling) widened to
  catch string-concat / `.join(':')` / any-delimiter reimplementations;
- a loose `>=12` microcopy population floor tightened to the **exact** committed count (14, both locales).

⭐ Plus a real defect the tests were blind to: `AccessibilityInfo.announceForAccessibility` was missing on
dismiss — AC4 requires the `dismissed` state be **ANNOUNCED**, not merely reflected in a label prop that a
focused screen reader will not necessarily re-read before the control it was on unmounts.

### W-6 — `<AuthenticatedFragment>` shipped as a structural guarantee, not a placeholder
It reads no cookie, no header, no session — and the file states why, at length, so a later edit cannot undo
it by accident: *"a component that CANNOT read auth cannot leak it, and cannot be made to by a later edit
that 'just adds a check'."* With three explicit `⛔ DO NOT`s, including ⛔ *do not add an `isAuthenticated`
prop* (a prop only moves the read to the caller and puts auth-derived branching back into cache-safe SSR
output).

### W-7 — Deferral language stayed precise under pressure
11a.6's deferred-work section closes four previously-routed items in **four different registers** and
refuses to collapse them: **CLOSED BY EDIT** (the `:491`→`:1819` amendment) · **CLOSED BY DESIGN RULING,
⛔ not by adding the field** (the `revision` descriptor) · **CLOSED BY EDIT** (the empty-title `". "` label)
· **NOT CLOSED — RE-ROUTED with a sharper trigger** (the row's `link CTA`, whose trigger fired and was
answered *"there is no destination"*). And item (d) is recorded **NOT ADDRESSED** — ⛔ not *closed*, ⛔ not
*resolved* — with the reason stated rather than implied.

⭐ The `:491`→`:1819` amendment also produced a **reusable convention**: amendments to
`ux-design-specification.md` land in **Appendix B** with the amended line edited in place at its own line
number, because ~150 citations across ~20 files reference that spec **BY LINE** and an inline note would
have silently shifted every `:1814-1821` anchor by nine lines — including the ones `<PinnedNotice>` itself

## 3. What Was Hard / What Leaked

### H-1 (headline) — the epic document is no longer a reliable build specification, and a scoped reconciliation does not reach far enough → **AI-11a-1**
Four of six stories found their AC defective. **AI-10-2 ran** — the 11a/11b prose was reconciled on
2026-08-19, with SD-1's findings recorded as **RECONCILED** blocks rather than silent rewrites. It was a
genuine success by its own terms.

⚠ **And it still missed SD-2**, because it ran on 2026-08-19 against the *retrospective's* findings, while
the contradiction it needed to catch was ruled on **2026-08-20** in `2026-08-20-141`. A reconciliation
gated at the **start** of an epic cannot carry that epic's own rulings forward.

⇒ **BigDev's disposition, 2026-08-23: (a) + (b).** Reconcile at the **end** of each epic against that
epic's rulings, **and** have the story-authoring pass's AC-reconciliation output write back into
`epics.md` rather than living only in the story file and the decision log.

### H-2 — a live public surface published a **deceased member as "Active"**
`2026-08-21-145` RD1. `/members` renders `members.state`, and **death is an overlay, not a lifecycle
label** ([[project_death_is_an_overlay_not_a_state]]) — so **every predicate over `members.state` is blind
to death by construction**. This **superseded `2026-08-20-143` D3(a) one day after it was ruled**, and
escalated to the Panel as `2026-08-21-146` (the amended member-facing sentence adopted; a member whose
account is frozen following a reported death is excluded from the public directory).

⚠ Caught by **second-round review**, not by any gate. The first round, the matrix gate, the tier-leak leg
and `ci:local` were all green through it. ⭐ It is the overlay/state seam surfacing on the **first surface
that published raw lifecycle state to the open internet** — and `2026-08-21-144` found the adjacent gap in
the same family: the public JSON route was emitting the **internal** value `lock-in`.

### H-3 — the AC10 anti-enumeration control was **vacuous by construction**
`2026-08-21-145` RD2: the anti-enumeration key is **attacker-chosen**, so the revert-sanity negative
control that would have caught it *could not*. Root cause is shared across three separate story analyses
(11a.3 Trap 2 — the SSR proxy collapses per-IP limiting to one bucket; 11a.3 Trap 3 — `trustProxy: true`
means the forwarded IP is caller-supplied; 11a.4 Trap 5 — *"flag scraping IPs" cannot be built as
written*). One sentence: **the recorded IP is not evidence.**

⭐ Related and correctly handled: 11a.3 Trap 8 states the abuse audit line is *"a COUNTER, not a forensic
record"* — and says so **in the code**, rather than letting the AC's wording imply otherwise.

### H-4 — a **recall regression escaped a precision fix**, inside the story that shipped the precision fix → **AI-11a-4**
`2026-08-22-150`. 11a.4's D2 tightened the `phone` pattern, but scoped its `'` and `/` exclusions to a
**bare character** rather than to the **markup signature** they were meant to detect. Two real regressions
followed: `'9876543210'` (a quoted phone number in prose) and `9876543210/9123456789` (a slash-separated
alternate number) both **silently evaded `detectNakedPii`** — reaching as far as the publish-time PII
backstop over **raw JSON text, where no markup exists at all**.

⚠ **AC1 explicitly required a precision regression net to exist BEFORE the regex moved. It existed.** The
net was scoped to precision; nothing asserted **recall** on the changed pattern. ⇒ a regression net that
only guards the direction you are pushing is not a net.

### H-5 — duplicated optimistic-dismissal logic across two components over the same endpoint
Deferred item (c). `<BannerHost>` and `PanchayatNoticeboard` each hold their own `bannerDismissalKey`-keyed
optimistic set, their own `dismiss.mutate({kind:'dismissed'})` and their own `onError` rollback — over the
**same banner, the same mutation, the same endpoint**. D7(b) (extract a shared `useBannerDismissal` hook)
was declined **on blast radius, ⛔ not on merit** — the same call `2026-08-22-152` D6(c) made.

⭐ Safe today, stated so the risk is not overestimated: the two can never disagree on screen, because
`<BannerHost>` self-suppresses on the panchayat route (its **fifth** suppression condition). ⚠ Where the
risk actually sits: the key format is safe **by construction** (one `bannerDismissalKey`, both call it),
but the **rollback posture is duplicated logic** — a fix applied to one is not a fix applied to the other.

### H-6 — a `done` story left an accessibility defect explicitly **NOT ADDRESSED**, with no CI net → **AI-11a-3**
Deferred item (d), two defects in `PanchayatNoticeboard.tsx`: the Masthead Pariwar-seal has
`accessibilityLabel` with ⛔ no `accessible={true}`; `PinnedSkeleton` announces `accessibilityRole="progressbar"`
with ⛔ no `accessibilityValue`.

⚠ The disposition is **NOT ADDRESSED** and it is **correct** — those elements are 11a.5's, and reaching into
them would be the scope drift D7(a) declined for `<BannerHost>`. What makes it a leak is the surrounding
fact: **11a.6's AC6 *was* semantic accessibility, editing that exact file**, and the seal defect is the
**same defect class** AC6 had just closed in the row.

⛔ **And it has no CI net.** `scripts/` holds **nineteen** invariant gates — `access-wrapper-invariants`,
`member-state-invariant`, `governance-boundary`, `microcopy`, `custom-field-governance`, and fifteen more —
and **none is an accessibility gate**. 11a.6 minted none ([[feedback_no_premature_package]]), so this class
of defect remains caught only by reading.

## 4. Key Insights / Lessons

### I-1 — When an epic AC and the architecture disagree, the architecture wins — and the AC is usually not merely wrong, it is *unbuildable*
All four cases share a shape: the AC assumed a capability — a viewer, a browser session, a component that
did not already exist — that **no substrate supplies**. This is not staleness. A stale AC describes
something that used to be true; these describe something that was **never** true. The distinction matters
because staleness is fixed by an update pass and unbuildability is fixed only by a **ruling**.

### I-2 — A gate can report green over nothing for four epics, and nothing will tell you
The FR-74 tier-leak leg was inert — a stub snapshot loader and a matrix declaring zero surfaces — while
**seven public pages shipped**. `[[feedback_gate_scope_semantic_coverage]]` says a green scan proves
nothing; this is the strongest instance yet, because the gate was not *mis-scoped*, it had **zero subjects**.
⭐ The generalization: a gate's output should report **what it checked**, not merely that it passed. The
armed gate now prints its surface count, field count, escalation count and — critically — a **BY DESIGN**
line naming what it does **not** check and where that check lives instead.

### I-3 — Built, correct, closed and **live** are four different facts
Row 17 is the seam, and BigDev's framing is the record: **the Public Trust Identity Shell is technically
delivered; the public identity is not operationally or publicly live.** 11a.3 is `done`, the kill switch
exists and is enforced in code, and 10.30 shipped the admin UI — and the row stays `open` because
≥2-trustee ratification is its **second** closure leg (*"⛔ A `done` story alone does NOT close this row"*).

⚠ Even after it closes, **the control is not immediate**: `/members` is declared `cache_policy: edge_cacheable`
with `s-maxage=300`, so a pulled Pariwar keeps being served real member names from every warm PoP,
**per page number**, until those entries expire. ⛔ The word *"immediate"* may not be used about this control.

⭐ And the honest fallback was **withdrawn, not replaced**: before `2026-08-21-147`, the real answer to
*"how do we pull a Pariwar today?"* was hand-run SQL. That answer is now forbidden — so there is currently
**no operational pull-lever for the directory at all**, which is precisely why the surface may not go live.

### I-4 — Withdrawing a premise on the merits is a first-class outcome
11a.4's D1 was re-asked and then **WITHDRAWN**: the trust's own contact channel is governed by
**REACHABILITY**, so obfuscating it is contrary to what it is *for*. This is
`[[feedback_trace_reachability_before_escalating]]` run in the opposite direction — prove the requirement
is **coherent** before building it. ⭐ Note what did *not* happen: the story did not quietly implement a
watered-down version to satisfy the AC's letter.

### I-5 — The un-mechanized half decays, and **accessibility is now that half**
Epic 10's E3, instantiated. Nineteen gates cover state machines, RBAC, governance boundaries, PII
scraping, microcopy, domain accessors, benefit mechanisms — and **zero** cover accessibility. On an epic
whose two closing stories were both design-system components carrying explicit a11y acceptance criteria,
and whose **successor epic makes an accessibility audit a launch-blocker** (11b.8 / UX-DR70).

### I-6 — A regression net must guard **both directions of the change it protects**
H-4's lesson, stated generally: a **precision** fix owes a **recall** assertion on the changed pattern, and
a recall fix owes a precision assertion. The asymmetric net is worse than no net, because it produces the
confidence of coverage without the coverage. → **AI-11a-4**.

### I-7 — A blocking pre-authoring gate is cheap when it is *targeted*
AI-10-4 cost one session and saved an epic. But its value came from being **specific** — it named four
rows, demanded a disposition for each, and gated one epic. ⭐ BigDev's disposition for SD-2 keeps that
property deliberately: **blocking pre-authoring substrate/publication-model validation, targeted — not a
universal ceremony.** A standing session at every epic boundary would become the thing that gets skipped.
